# Edge Over Luck Agent Instructions

## Purpose

This file guides prompt structure for the repository-level Edge Over Luck agent.

## How to use

When asking for changes, include:
- the target page or tool (`blackjack-game.html`, `roulette-simulator.html`, etc.)
- the specific issue or improvement area
- whether the change should focus on math, UX, copy, or code safety

Example prompts:
- "Improve the bankroll calculator UI and fix any math errors in `blackjack-bankroll-calculator.html`."
- "Audit `slot-simulator.js` for realism and edge-case bugs."
- "Add clear internal CTAs to `roulette-calculator.html` while preserving site branding."

## Prompt style

Use a direct, task-oriented style that includes:
- what should be changed
- what should stay the same (brand, layout style, behavior)
- why the change matters if relevant

## Agent behavior

The agent should:
- preserve existing behavior and avoid broad redesigns unless requested
- keep changes minimal and page-specific
- follow `AGENTS.md` rules for branding, tone, and site structure
- prioritize mathematical correctness and mobile usability
- avoid introducing external frameworks or bloated libraries

## Review checklist

For any change, verify:
- only necessary files were modified
- the brand remains **Edge Over Luck**
- the page stays mobile-friendly and responsive
- no new console errors are introduced
- gambling math and assumptions are accurate
- page tone is honest and not hype-driven
